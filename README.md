## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Playwright
- Git e GitHub

## Funcionalidades
- Página Inicial
- Serviços disponíveis
- Página de Eventos
- Pesquisa dinâmica de eventos
- Sistema de favoritos usando LocalStorage
- Página de Contato
- Validação em JavaScript
- Mensagens de erro e sucesso sem recarregar a página

## Responsividade
- Projeto desenvolvido seguindo a estratégia Mobile First.

## Testes
- Os testes automatizados foram implementados utilizando Playwright.

npx playwright test

## Limitações
- Projeto exclusivamente de front-end.
